# Day 15 - String Problems

## Problems Solved

### 1. 28. Find the Index of the First Occurrence in a String
**Approach:** Brute force string matching - iterate through haystack and compare each position with needle
**Time Complexity:** O(n*m)
**Space Complexity:** O(1)

### 2. 459. Repeated Substring Pattern
**Approach:** Check all possible divisors of string length and verify if pattern repeats
**Time Complexity:** O(n²)
**Space Complexity:** O(1)

### 3. 796. Rotate String
**Approach:** Generate all possible rotations and compare with goal string
**Time Complexity:** O(n²)
**Space Complexity:** O(n)

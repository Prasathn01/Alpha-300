# Day 16 - Sliding Window Problems

## Problems Solved

1. **[3. Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/)**
   - Find the length of the longest substring without repeating characters
   - Approach: Sliding window with set tracking

2. **[424. Longest Repeating Character Replacement](https://leetcode.com/problems/longest-repeating-character-replacement/)**
   - Find the length of the longest substring after at most k character replacements
   - Approach: Sliding window with frequency map

3. **[438. Find All Anagrams in a String](https://leetcode.com/problems/find-all-anagrams-in-a-string/)**
   - Find all start indices of anagrams of a pattern string in a source string
   - Approach: Sliding window with character frequency comparison

# Day 18 - String Organization

## Problems Solved

1. **[791. Custom Sort String](https://leetcode.com/problems/custom-sort-string/)**
   - Sort a string according to a custom order string
   - Approach: Count characters from order string, then append remaining characters

2. **[767. Reorganize String](https://leetcode.com/problems/reorganize-string/)**
   - Reorganize string so no two adjacent characters are the same
   - Approach: Place most frequent character at even indices, fill remaining characters

3. **[451. Sort Characters By Frequency](https://leetcode.com/problems/sort-characters-by-frequency/)**
   - Sort characters in string by their frequency in descending order
   - Approach: Count frequencies, sort by count, build result string
